# Project Rules

## 🚫 Git & Remote Repository Policy
- **KHÔNG TỰ ĐỘNG PUSH CODE LÊN GITHUB**:
  - AI Assistant không được tự động thực hiện `git push` lên GitHub.
  - Các bước commit code có thể chuẩn bị ở local, nhưng việc push code lên remote repository bắt buộc phải có xác nhận/yêu cầu trực tiếp từ người dùng.
